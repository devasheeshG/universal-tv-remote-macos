# Universal TV Remote for Mac 1.0.3

Separates current discoveries from saved devices and explains why an online Fire TV can still be unavailable to the remote.

## Changes

- Group TVs into “Discovered on this network” and “Saved · not currently discovered.”
- Refresh discovery periodically and expire SSDP sightings after 45 seconds without a reply.
- Read the FireTVRemote DIAL service status when the control API is unreachable.
- Explain when the TV is online but its remote service is stopped. The power button explicitly starts/wakes that service; background monitoring and Reconnect do not.

## Install

Requires **macOS 14 or later**. Download `Universal.TV.Remote.for.Mac.dmg`,
open it, and drag **Universal TV Remote.app** onto **Applications**.
On first launch, **right-click → Open** and allow local network access when
macOS asks. The app is ad-hoc signed and not notarized.

## Compatibility

“Connected” describes remote-service availability, not the power state of
an attached display. A powered Fire TV Stick can remain reachable while
its television is off. Available commands and app queries vary by firmware.
Samsung, LG, and Roku drivers have not been verified on physical hardware by
the developer.
