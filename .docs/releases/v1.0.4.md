# Universal TV Remote for Mac 1.0.4

Improves pairing and panel sizing so the remote stays usable when its content changes.

## Interface fixes

- Keep the header visible and constrain the panel to the available screen height. Scroll long content when needed.
- Resize the panel to its content and keep its top edge anchored when switching between connected and pairing states.
- Add a centered pairing card with a larger PIN/code field and a full-width Pair button.
- Filter Fire TV input to four numeric digits and Android TV input to six hexadecimal characters. Require the complete code before submission.
- Prevent remote keyboard shortcuts from intercepting pairing input.
- Fit the app shortcut row within the panel and allow expanded app labels to wrap to two lines.

## Install

Requires **macOS 14 or later**. Download `Universal.TV.Remote.for.Mac.dmg`, open it, and drag **Universal TV Remote.app** onto **Applications**. On first launch, **right-click → Open** and allow local network access when macOS asks. The app is ad-hoc signed and not notarized.

## Compatibility

“Connected” describes remote-service availability, not the power state of an attached display. A powered Fire TV Stick can remain reachable while its television is off. Available commands and app queries vary by firmware. Samsung, LG, and Roku drivers have not been verified on physical hardware by the developer.

## Distribution update

This historical release now provides a DMG containing its original app bundle. The app binary and version are unchanged; the ZIP packaging and release notes were replaced.
