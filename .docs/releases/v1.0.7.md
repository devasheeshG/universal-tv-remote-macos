# Universal TV Remote for Mac 1.0.7

Fixes the remaining flicker when collapsing installed apps, restores system-managed panel appearance, and removes hard line wrapping from project prose.

## Interface fixes

- Keep one content tree mounted while expanding and collapsing installed apps, preserving the remote controls, input fields, and focus instead of replacing the entire body.
- Measure content height directly and resize and reposition the panel in one frame update, avoiding an intermediate resized-but-unanchored window.
- Remove the extra translucent content background, custom outer corner clipping, and forced dark appearance. macOS supplies the menu-bar window's native background and outer shape.
- Use appearance-aware control fills and text-field colors so the remote works in both light and dark mode.
- Keep TV selection, settings, pairing, rename, and add-TV forms inside the same window.

## Documentation

- Keep each prose paragraph on one source line in the README, release notes, project documentation, and explanatory comments. Editors and renderers choose how to wrap it for the available screen width.
- Preserve code blocks, lists, tables, diagrams, and copyright headers.
- Reformat the published release-note bodies for versions 1.0.1–1.0.6 to match their checked-in files.
- Add repository writing guidance to preserve this formatting in future changes.

## Install

Requires **macOS 14 or later**. Download `Universal.TV.Remote.for.Mac.dmg`, open it, and drag **Universal TV Remote.app** onto **Applications**. On first launch, **right-click → Open** and allow local network access when macOS asks. The app is ad-hoc signed and not notarized.

## Compatibility

The remote uses Apple's window-style menu-bar panel for interactive controls; it is not a text-only menu. “Connected” describes remote-service availability, not the power state of an attached display. A powered Fire TV Stick can remain reachable while its television is off. Available commands and app queries vary by firmware. Samsung, LG, and Roku drivers have not been verified on physical hardware by the developer.
