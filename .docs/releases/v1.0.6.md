# Universal TV Remote for Mac 1.0.6

Removes the collapse-then-expand transition when opening installed apps and updates how releases are distributed.

## Interface fix

- Apply app-list expansion and collapse in one transaction, without animating through intermediate layouts that shrink the entire remote.
- Keep the final expanded layout, scrolling behavior, and pinned header.

## Build and distribution

- Distribute a DMG containing Universal TV Remote.app and an Applications shortcut, replacing ZIP downloads.
- Publish written, versioned release notes from .docs/releases/ instead of generating release bodies from commit messages.
- Read the release version from VERSION, or from an explicit v* tag.
- Remove the automated test suites and the CI test step. The release workflow builds and packages the app.
- Keep only the selected remote screenshot in the README.

## Install

Requires **macOS 14 or later**. Download `Universal.TV.Remote.for.Mac.dmg`,
open it, and drag **Universal TV Remote.app** onto **Applications**.
On first launch, **right-click → Open** and allow local network access when
macOS asks. The app is ad-hoc signed and not notarized.

## Compatibility

“Connected” describes remote-service availability, not the power state of
an attached display. A powered Fire TV Stick can remain reachable while
its television is off. Available commands and app queries vary by firmware.
Samsung, LG, and Roku drivers have not been verified on physical hardware by
the developer.
