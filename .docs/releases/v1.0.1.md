# Universal TV Remote for Mac 1.0.1

First public release of a native macOS menu-bar remote for Fire TV, Android / Google TV, Samsung Tizen, LG webOS, and Roku.

## Features

- Discover TVs on the local network using Bonjour and SSDP, or add a TV by IP address.
- Pair supported TVs once and retain their credentials. Rename TVs and restore the last selection.
- Control power, direction/OK, back, home, menu, media transport, volume, and mute.
- Send text to TV input fields and launch apps from the shortcut row. Expand the row to see more installed apps.
- Use keyboard shortcuts while the remote is open, and enable Launch at Login from settings.

## Install

Requires **macOS 14 or later**. Download `Universal.TV.Remote.for.Mac.dmg`,
open it, and drag **Universal TV Remote.app** onto **Applications**.
On first launch, **right-click → Open** and allow local network access when
macOS asks. The app is ad-hoc signed and not notarized.

## Compatibility

“Connected” describes remote-service availability, not the power state of
an attached display. A powered Fire TV Stick can remain reachable while
its television is off. Available commands and app queries vary by firmware.
Samsung, LG, and Roku drivers have not been verified on physical hardware by
the developer.
