# Universal TV Remote for Mac 1.0.5

Keeps navigation and device management inside the remote window.

## Interface changes

- Replace the TV-picker dropdown with an inline list of live and saved TVs.
- Replace the settings dropdown with an inline panel for rename, re-pair, forget, Launch at Login, and quit.
- Keep pairing, rename, and add-TV forms inside the same window, with back navigation to the remote.
- Use inline radio buttons for the add-TV brand selector.
- Suspend remote keyboard shortcuts while using settings, TV selection, or input forms.

## Install

Requires **macOS 14 or later**. Download `Universal.TV.Remote.for.Mac.dmg`,
open it, and drag **Universal TV Remote.app** onto **Applications**.
On first launch, **right-click → Open** and allow local network access when
macOS asks. The app is ad-hoc signed and not notarized.

## Compatibility

“Connected” describes remote-service availability, not the power state of
an attached display. A powered Fire TV Stick can remain reachable while
its television is off. Available commands and app queries vary by firmware.
Samsung, LG, and Roku drivers have not been verified on physical hardware by
the developer.

## Distribution update

This historical release now provides a DMG containing its original app
