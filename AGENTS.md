# Writing and formatting

- Write each prose paragraph on one source line in Markdown, README files, release notes, and explanatory code comments. Let the editor or renderer wrap it to the available screen width.
- Keep paragraph breaks, headings, list items, tables, fenced code blocks, diagrams, copyright headers, and syntax-driven code structure intact.
- Do not impose an arbitrary prose column limit or split sentences across source lines to satisfy one.
- Release-note bodies come from `.docs/releases/v<version>.md`; keep those files and the corresponding GitHub release bodies consistent.
